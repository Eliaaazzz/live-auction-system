## Live demo — exact commands

Pre-conditions on demo machine:
- Docker Desktop running
- Repo at `main` HEAD (PR #13 + #19 + #21 ideally all merged)
- Port 8080 free
- Browser ready

```bash
# 1. Up the stack (~60s build + healthcheck)
git fetch origin main && git checkout main && git pull
make up

# Expected: 4 containers Healthy
#   ✓ mysql        Healthy
#   ✓ redis        Healthy
#   ✓ ai-sidecar   Healthy
#   ✓ lumen        Healthy

# 2. Seed dev data
make seed
# Expected: "seed: created seller_demo, buyer_demo, prod_demo, auc_demo (LIVE)"

# 3. Run e2e — proves the wire end-to-end
make e2e-dummy-bid
# Expected: "E2E_AUCTION_ID=auc_<hex>"
#           "e2e-dummy-bid: PASS"

# 4. Replay verifier — proves correctness
make verify
# Expected: "consistent: stream=1 mysql=1 (auction=auc_<hex>)"

# 5. (Optional) Two-tab human demo
open "http://localhost:8080/admin.html"
open "http://localhost:8080/room.html?auction=auc_demo"
open "http://localhost:8080/room.html?auction=auc_demo"  # 2nd viewer tab
# Click "Bid" in any tab → other tabs update within ~150ms via WS broadcast
```
