## Live demo — exact commands

**Pre-conditions** (verified pre-call):
- Docker Desktop running
- Repo at `main` HEAD (PR #13 + #19 + #21 merged; PR #18 / #26 ideally merged or rebased onto main)
- Ports 8080 / 3000 / 9090 free (verified via `lsof`)
- Browser ready, `auc_demo` page bookmarked

```bash
# 1. Up the stack WITH observability (~90s first build, ~30s cached)
git fetch origin main && git checkout main && git pull
make up-obs

# Expected: 8 containers Healthy
#   ✓ mysql + redis + ai-sidecar + lumen
#   ✓ prometheus + grafana
#   ✓ redis-exporter + mysqld-exporter

# 2. Seed dev data (idempotent)
make seed
# Expected: "seed: created seller_demo, buyer_demo, prod_demo, auc_demo (LIVE)"

# 3. Run e2e — proves the wire end-to-end
make e2e-dummy-bid
# Expected: "E2E_AUCTION_ID=auc_<hex>"
#           "e2e-dummy-bid: PASS"

# 4. Verifier stub — count consistency (NOT full Replay Verifier; that lands T6)
make verify
# Expected: "consistent: stream=N mysql=N (auction=auc_<hex>)"

# 5. Two-tab human demo — use the PRE-SEEDED auc_demo so admin + room are same auction
open "http://localhost:8080/admin.html"   # for evidence-stub click in beat 3
open "http://localhost:8080/room.html?auction=auc_demo"
open "http://localhost:8080/room.html?auction=auc_demo"  # 2nd viewer tab
# Click "Bid" in one tab → other tab updates via WS broadcast.

# 6. (Beat 3) Evidence stub — show one explicit click
curl -s http://localhost:8080/api/auctions/auc_demo/evidence | jq
# Expected: T1 evidence stub object with currentPriceCents, winnerId, seq,
#           eventsCount, factsConfirmed, eventsHash=null + the note
#           "T1 evidence stub; events_hash chain lands in T4"

# 7. (Beat 4) Dashboard
open "http://localhost:3000/d/lumen-auction-realtime"
# 3/3 scrape targets UP. App-level panels show "no data" pending T-later
# /metrics handler — that's accurate to current state.
```
