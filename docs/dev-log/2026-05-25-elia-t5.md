## What changed
1. **Backpressure channel split** (`ws.go`) — each `Conn` now has two send lanes:
   - **critical** (`send`): bid acks, `AUCTION_*` terminals, `ROOM_SNAPSHOT`, catchup. Full → **force-close** (client reconnects + re-syncs; never a silent loss).
   - **best-effort** (`lossy`): `PONG` (+ future presence/chat). Full → **drop the frame**, keep the connection.
   `writePump` drains critical **with priority** over lossy (a flood of heartbeats can't delay a bid ack). All sends stay non-blocking (one slow client never stalls the room). `PONG` now routes via `pushLossy`. A force-close logs `ws backpressure: force-closing slow client` for ops.
2. **Multi-gateway fanout** — verified the existing topology (no code change needed): two independent hubs, each its own Pub/Sub subscription, both fan a bid out to their own room member from the canonical Stream.
