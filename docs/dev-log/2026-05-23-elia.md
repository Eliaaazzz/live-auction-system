## Entry 2 — code-review round 1 (3 angles) + fixes

**What changed** — ran diverse review (3 finder angles: line-by-line / cross-file / security+CI), then fixed 8 findings:

6. Secret guard used `grep -rIn` (skips binaries) → a secret in the committed PDF wouldn't be caught. Fixed: `git grep` (scans tracked files incl. binaries) in CI + Makefile.
7. `go mod tidy` result wasn't verified in CI → stale go.mod false-green. Fixed: `git diff --exit-code` gate.
8. GET auction returned 200-empty for unknown id. Fixed: 404 + MySQL status fallback for not-yet-frozen.
